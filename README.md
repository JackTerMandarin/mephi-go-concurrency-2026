# Поиск максимума в большом слайсе

Задание по многопоточности в Go на основе
[шаблона Яндекс Практикума](https://github.com/Yandex-Practicum/go1fl-sprint9-final-tpl).

Программа создаёт слайс из 100 миллионов положительных чисел и ищет максимум
двумя способами: последовательно и в восьми горутинах. Для обоих способов
используется один слайс. Время поиска выводится в микросекундах; генерация
данных в него не входит.

Каждая горутина обрабатывает свою часть и записывает результат в отдельный
элемент слайса максимумов. После `sync.WaitGroup.Wait` находится общий максимум.
Остаток от деления достаётся последней части. Слайсы короче восьми элементов
обрабатываются последовательно. Для пустого слайса результат равен нулю.

Требуется Go 1.24.1 или новее.

```sh
go run .
go test ./...
go test -race ./...
go vet ./...
```

На 64-битной системе исходный слайс занимает около 800 МБ памяти.
Ускорение зависит от процессора и текущей нагрузки: восемь горутин
не гарантируют восьмикратного ускорения.
